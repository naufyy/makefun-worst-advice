The Check Engine Light: a one-line entry where an AI assistant confidently advises that a square of electrical tape over the dashboard light resolves the warning. It is the worst kind of advice: fast, cheap, and the light really does vanish, while whatever is wrong under the hood quietly gets worse.

## Run it

```sh
python3 main.py
```
